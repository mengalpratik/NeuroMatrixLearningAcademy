# NeuroMatrix Learning Academy — Complete 112-Day Curriculum Reference

This document outlines the full 16-week, 112-day curriculum structure. Every day is directly addressable in the application workspace via `/curriculum/:day` (or `/lessons/:day`).

---

## Phase 1: Foundations & Python Engineering (Weeks 1–4, Days 1–28)

### Week 1 — Python Fundamentals (Days 1–7)
- **Day 1**: Python setup, interpreter, print, comments, variables (`/curriculum/1`)
- **Day 2**: Data types, type conversion, input (`/curriculum/2`)
- **Day 3**: Operators and Boolean logic (`/curriculum/3`)
- **Day 4**: Conditions and branching (`/curriculum/4`)
- **Day 5**: Loops and iteration (`/curriculum/5`)
- **Day 6**: Strings and string methods (`/curriculum/6`)
- **Day 7**: Week 1 Revision & Device-Status CLI Project (`/curriculum/7`)
  - *Milestone 1*: Build a command-line tool that parses terminal flags, checks device telemetry, and prints formatted status reports.

### Week 2 — Data Structures and Functions (Days 8–14)
- **Day 8**: Lists & dynamic arrays (`/curriculum/8`)
- **Day 9**: Tuples, immutability & sets (`/curriculum/9`)
- **Day 10**: Dictionaries and nested data structures (`/curriculum/10`)
- **Day 11**: Functions, parameters & return values (`/curriculum/11`)
- **Day 12**: Function arguments, *args, **kwargs & scope (`/curriculum/12`)
- **Day 13**: Comprehensions, iteration helpers & sorting (`/curriculum/13`)
- **Day 14**: Week 2 Milestone: In-Memory Task Manager & Node Registry (`/curriculum/14`)
  - *Milestone 2*: Develop an in-memory task dispatcher and device node registry with filtering, prioritization, and sorting.

### Week 3 — Python Engineering (Days 15–21)
- **Day 15**: Exceptions and error handling (`/curriculum/15`)
- **Day 16**: Files and JSON persistence (`/curriculum/16`)
- **Day 17**: Modules, packages, imports (`/curriculum/17`)
- **Day 18**: Classes and objects (`/curriculum/18`)
- **Day 19**: Inheritance, composition, properties, dataclasses (`/curriculum/19`)

- **Day 21**: Week 3 Milestone: OOP Node Agent Core & Testing (`/curriculum/21`)
  - *Milestone 3*: Architect an object-oriented Python package with Device and Task domain models, custom exception hierarchies, and JSON state persistence.

### Week 4 — Web Foundations (Days 22–28)
- **Day 22**: Linux terminal, processes, ports, Git (`/curriculum/22`)
- **Day 23**: Internet, client-server architecture, DNS, HTTP (`/curriculum/23`)
- **Day 24**: HTTP methods, status codes, headers, CORS (`/curriculum/24`)
- **Day 25**: HTML fundamentals and forms (`/curriculum/25`)
- **Day 26**: CSS fundamentals and box model (`/curriculum/26`)
- **Day 27**: Flexbox, Grid, responsive design, accessibility (`/curriculum/27`)
- **Day 28**: Week 4 Milestone: Static NeuroMatrix Dashboard (`/curriculum/28`)
  - *Milestone 4*: Craft a responsive static cybersecurity web dashboard showcasing live node telemetry cards, status badges, and action controls.
